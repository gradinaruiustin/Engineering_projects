# RPG Dungeon 2D

A **2D dungeon crawler RPG** built in Python using `pygame`. Explore medieval dungeons, fight monsters, collect loot, upgrade your equipment, and trade in a village. This project is intended as a foundation for building a more advanced RPG system.

## Features

- **Dungeon Exploration**: Procedurally generated medieval dungeons with multiple rooms, corridors, and treasure chests.
- **Monsters**: Zombie, Skeleton, Golem, Goblin, Slime, Ghost, Wizard, Demon, Dragon.
- **Player Actions**:
  - Move with `W`, `A`, `S`, `D`
  - Attack with `SPACE`
  - Open chests with `E`
- **Items**:
  - Weapons: Sword, Katana, Axe, Pickaxe, Bow, Magic Staff, Magic Book
  - Armor: Helmet, Chestplate, Gloves, Boots
  - Consumables: Potions, Food
  - Loot from monsters and chests
- **Item Upgrades**: Weapons and armor can be upgraded to increase power and value.
- **Coins System**: Bronze, Silver, and Gold coins used for trading and rewards.
- **Inventory System**: Collect, equip, and manage weapons, armor, and consumables.
- **Dungeon Exit and Village**: Exit the dungeon to reach a village with NPCs to trade items.
- **User Interface (UI)**: Displays current coins, inventory, and basic stats.
